    Основные формулы:
    • n = m / M = V / Vm (Vm = 22.4 л/моль) = N / Na (Na = 6.02·10²³)
    • ω(в-ва) = m(в-ва) / m(р-ра) · 100%
    • C(молярная) = n / V(р-ра, в литрах)
    • Выход η = m(практ) / m(теор) · 100%
    Индикаторы (Кислота / Нейтр / Щёлочь):
    • Лакмус: Красный / Фиол / Синий
    • Метилоранж: Красный / Оранж / Жёлтый
    • Фенолфталеин: Бесцв / Бесцв / Малиновый
    Газы и осадки:
    • BaSO4 (бел), AgCl (бел творож), AgBr (желтов), AgI (жёлт), Cu(OH)2 (голуб), Fe(OH)3 (бурый)
    • H2 (хлопок), O2 (тлеющая лучинка), CO2 (мутнеет известк. вода), NH3 (нашатырь, синеет лакмус)
